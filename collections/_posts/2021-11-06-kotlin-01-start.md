> 본 강의는 코틀린(Kotlin)의 문법강의가 아닌, 프로그래밍 훈련을 위한 강의입니다.
> 따라서, 본 강의에서 알려드리는 내용만으로 코딩훈련에 임하시기 바랍니다.

코틀린 공부를 위해서는 가장 먼저 개발환경을 셋팅해야 합니다.

설치하지 않고 웹브라우저 상에서 공부하는 방법도 있지만, 어차피 개발환경은 구축을 해야하니 IDE(통합개발환경)를 이용해서 강의를 진행하도록 하겠습니다.

우리는 IDE로 **IntelliJ IDEA**를 사용해서 프로그래밍을 시작해보겠습니다. 먼저 아래 주소로 이동합니다.

URL : [https://www.jetbrains.com/ko-kr/](https://www.jetbrains.com/ko-kr/)

위 주소로 이동하면 아래와 같은 Jetbrain 사이트가 나옵니다.

![image](/assets/images/2021-11-06-kotlin-01-start/1.png){: .align-center}

상위 메뉴에서 "개발자 도구"를 클릭 한 뒤, **IntelliJ IDEA**를 선택합니다.

![image](/assets/images/2021-11-06-kotlin-01-start/2.png){: .align-center}

**IntelliJ IDEA** 페이지로 넘어가면 **다운로드** 버튼을 클릭합니다.

![image](/assets/images/2021-11-06-kotlin-01-start/3.png){: .align-center}

우리는 무료버전인 **Community** 버전을 다운로드 하겠습니다. **다운로드** 버튼을 눌러 다운로드 합니다.

![image](/assets/images/2021-11-06-kotlin-01-start/4.png){: .align-center}

다운받은 파일을 실행하면 아래와 같은 창이 뜹니다. **Next** 버튼을 클릭합니다.

![image](/assets/images/2021-11-06-kotlin-01-start/5.png){: .align-center}

아래 화면으로 넘어가면 건드리지 않고, **Next**를 클릭합니다.

![image](/assets/images/2021-11-06-kotlin-01-start/6.png){: .align-center}

모두 체크하고 **Next** 버튼을 눌러줍니다.

![image](/assets/images/2021-11-06-kotlin-01-start/7.png){: .align-center}

건드리지 않고, **Install** 버튼을 클릭합니다.

![image](/assets/images/2021-11-06-kotlin-01-start/8.png){: .align-center}

아래와 같이 설치화면이 진행됩니다.

![image](/assets/images/2021-11-06-kotlin-01-start/9.png){: .align-center}

설치가 완료되고 나면 **Finish** 버튼을 누르고 재부팅을 시켜줍니다.

![image](/assets/images/2021-11-06-kotlin-01-start/10.png){: .align-center}

PC를 재부팅한 뒤, **IntelliJ IDEA**를 실행합니다. 아래 창이 뜨면 체크하고 **Continue**를 클릭합니다.

![image](/assets/images/2021-11-06-kotlin-01-start/11.png){: .align-center}

버그나 에러를 분석할 수 있는 데이터를 보낼건지 물어보는 화면입니다. 자유롭게 선택합니다.

![image](/assets/images/2021-11-06-kotlin-01-start/12.png){: .align-center}

선택을 완료하고 나면 프로그램이 실행됩니다. 아래는 프로그램이 실행된 모습입니다.

![image](/assets/images/2021-11-06-kotlin-01-start/13.png){: .align-center}

다음 장에서는 Hello world 프로젝트를 시작해보겠습니다.
